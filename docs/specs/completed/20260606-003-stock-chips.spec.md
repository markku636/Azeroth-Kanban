> 建立日期: 2026-06-06
> 狀態: ✅ 已完成
> 關聯計劃書: ai-frolicking-fairy.md（優化計劃 Phase 1）

## 目標

加入台股最大賣點「籌碼面」(免費資料):融資融券餘額、外資持股比例(既有三大法人買賣超續用)。注入研究報告 + console 籌碼卡 + 籌碼訊號/警報。

> Spike 發現:`TaiwanStockHoldingSharesPer`(集中度/千張大戶)需付費 → 本階段不用;改用融資券 + 外資持股(免費)。

## 邏輯
- `chips.ts`:`fetchMarginShort(symbol,start)` → 融資餘額(MarginPurchaseTodayBalance)、融券餘額(ShortSaleTodayBalance);`fetchForeignHolding(symbol,start)` → 外資持股比例(ForeignInvestmentSharesRatio);`loadChips(symbol)` 合併近 N 日 + upsert StockChip。
- `StockChip`:symbol, trade_date, margin_balance, short_balance, foreign_ratio;唯一鍵 symbol+date。
- 訊號:融資連續下降 + 法人買超 = 偏多訊號之一(併入 generateSignal rationale 或附加)。
- 報告:claudeResearch facts 加「融資餘額/融券/外資持股比例 + 近期變化」。
