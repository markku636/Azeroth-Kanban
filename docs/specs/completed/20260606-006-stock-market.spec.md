## 邏輯
- TWSE MI_INDEX：找「發行量加權股價指數」取漲跌%;類股 = 指數名含「類」者(電子類/金融保險類…)取漲跌%排序。
- STOCK_DAY_ALL：Change>0 漲家數、<0 跌家數、=0 平盤。
- loadMarket：合併 → upsert MarketDaily(sectors 存 JSON 陣列)。
- 大盤頁:加權指數卡(收盤+漲跌%)、漲跌家數(紅綠長條)、類股強弱排行。
