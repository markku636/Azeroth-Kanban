## 目標

新增「單一個股 KD 策略回測」：使用者輸入代號 + 可調 KD 參數 + 本金/費率，背景 worker 以近 5 年
歷史日 K 逐日模擬買賣，落庫 `backtest_run`，前端呈現勝率 / 5 年總損益金額 / 風險指標 / 權益曲線 / 交易明細。

## 背景

專案已有 KD 計算與 K 線買賣箭頭，但無回測功能。回測引擎以純函式置於 `common`（可測、可複用）。
策略可信度關鍵：**訊號於第 i 日收盤確認，第 i+1 日開盤價成交**（避免未來函數）。

> 參考知識/實作：`admin/src/lib/kd-verdict.ts`（KD 公式）、`worker/src/jobs/analysis.ts`（job 流程）、
> `worker/src/data/cache.ts`（K 線快取）、`common/src/scoring-strategy.ts`（common 純函式慣例）。

## 邏輯變更點

### common — 回測引擎

- `stochasticSeries(klines, period=9, signal=3)`：回傳每日 `{ k, d }`（與 kd-verdict 同公式：
  RSV = (C − Ln)/(Hn − Ln)×100，K = 前K×2/3 + RSV/3，D = 前D×2/3 + K/3；初值 50）。
- `runKdBacktest(klines, params)`：
  - 狀態機（flat ↔ holding），單一持倉、全進全出、複利。
  - 買進：K 上穿 D 且 K < `oversold`；隔日開盤進場。
  - 賣出：K 下破 D 且 K > `overbought`；隔日開盤出場。選用停損/停利於觸價當日成交（優先於 KD）。
  - 張數 = `floor(capital / (entryPrice × 1000)) × 1000`；不足一張則該訊號跳過。
  - 費用：買手續費 = 額×`feeRate`；賣手續費 = 額×`feeRate` + 證交稅 額×`taxRate`。
  - 期末仍持倉 → 以最後一日收盤平倉（exitReason='end'）。
  - 產出 `trades[]`、每日 `equityCurve[]`（持倉以當日收盤市值計）、買進持有 benchmark。
- `computeStats`：勝率、總/年化報酬、最大回撤（權益曲線峰谷）、獲利因子、波動度（每日權益報酬 stddev）、
  類夏普（年化報酬/年化波動）、平均持有天數、平均盈虧、單筆最大虧損。

### worker

- `loadKlineRange`：先 `getCachedKline(symbol, start, end)`，資料涵蓋不足則 `fetchDailyKline` 補抓 +
  `upsertDailyPrices` 回填後重讀。
- `processBacktest`：`startRun('backtest', ...)` → `loadKlineRange` →（資料過少回失敗）→ `runKdBacktest`
  → `prisma.backtestRun.update`（status done + 摘要欄 + JSON）→ `finishRun`；catch → `failRun` + status failed。

### admin

- `runBacktest`：Zod 驗證 → 建 `BacktestRun(pending)` → `enqueueBacktest` → 回 `{ runId }`。
- `getBacktestResult(runId)`：回單筆（前端輪詢 status 至 done/failed）。
- 頁面：表單 → 取 runId → 輪詢 → 結論卡（金額/勝率/買進持有對照）+ 風險卡 + 權益曲線 + 交易明細表；
  頁尾 `STOCK_DISCLAIMER` + 「隔日開盤成交、未含滑價」說明。

## Bug Log

### Bug #1: 高價股回測全 0（0 交易 / 報酬 0% / 買進持有 0%）

| 分類 | 內容 |
| --- | --- |
| **[Bug]** | 2330 近 1 年回測 0 筆交易、報酬 0%、買進持有 0%。 |
| **[Root Cause]** | 部位採整張(1000 股)制。台積電 ~1025/股，一張 ~102.5 萬 > 本金 100 萬 → `floor(100萬/102.5萬)=0 張` → 永遠買不進；buyHold 同理。即使可買 1 張也因閒置現金嚴重低估報酬。 |
| **[Solution]** | 改零股：`shares = floor(capital / (price × (1+feeRate)))`（進場 + buyHold 兩處），全額投入。移除 `SHARES_PER_LOT`。 |
| **[Prevention]** | 新增高價股單元測試（每股 1000、本金 100 萬仍進場且非整張）；交易明細「張數」改「股數」；新增 0 交易友善提示 + 「資料來源與計算方式」透明化卡片。 |

> 驗證（真實 2330 近 1 年）：修正後 4 筆交易、勝率 75%、策略 +12.2%、買進持有 +129.4%（理論 ~131%），首筆 670 股（零股）。common 測試 9 案全綠、三 workspace type:check 全綠。
